# ADR-035: Skill file markup — Markdown only (superseded)

This record held the markup-only slice of skill design: skill files are written in
Markdown process only — no HTML, no author-invented XML. It was folded into the skill
design domain ADR per the domain-grain rule
([ADR-029](ADR-029-atomic-adrs-one-decision-each.md)); the live record is
**[ADR-030-skill-design-and-canonical-format.md](ADR-030-skill-design-and-canonical-format.md)**,
where the markup rules are Decision §2. Do not amend this file.

was renumbered to `ADR-035` on 2026-07-25 to restore unique sequential ids.
